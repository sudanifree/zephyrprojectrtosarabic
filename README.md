# مشروع Zephyr باللغة العربية

هذا المستودع يضم مشروع Zephyr، وهو نظام تشغيل آني (RTOS) مفتوح المصدر للأجهزة
المضمنة ومحدودة الموارد. يجمع هذا الإصدار بين وثائق عربية أساسية ودعم العرض
من اليمين إلى اليسار (RTL) في موقع الوثائق.
